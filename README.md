# README

## Overview
This repository collects tools, scripts, notes, and lessons learned from security testing work. It is What If Security's living lab and reference, but it is public for anyone who wants to follow along, contribute, or reuse tools under the license below. The repository is hosted by my company What If Security LLC.

## Contribution Guide

Contributions are welcome. Please follow these basic steps:
* Open an issue first if you are proposing a new tool a major change or a lab scenario. This helps avoid duplicated work.  
* For code or doc changes fork the repository create a topic branch then open a pull request.  
* Include clear usage examples required dependencies and safety notes for any tool or script.  
* Keep commits small and focused and add tests if applicable.

Do not publish the issue publicly before disclosure is coordinated.
