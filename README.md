# README

## Overview
This repository collects tools scripts notes and lessons learned from security testing work. It is my personal living lab and reference but it is public for anyone who wants to follow along contribute community notes or reuse tools under the license below. The repository is hosted by my company What If Security LLC.

**Purpose**  
* Capture useful tools scripts and configurations I build during testing  
* Record techniques and takeaways so they are easier to reproduce later  
* Provide a place for the community to add notes examples and improvements  
* Offer ready to use references for learning and teaching


## Contribution Guide

Contributions are welcome. Please follow these basic steps:

* Open an issue first if you are proposing a new tool a major change or a lab scenario. This helps avoid duplicated work.  
* For code or doc changes fork the repository create a topic branch then open a pull request.  
* Include clear usage examples required dependencies and safety notes for any tool or script.  
* Keep commits small and focused. Add tests if applicable.  
* Be respectful and keep discussions constructive.

## Code of Conduct

This project follows a simple community code of conduct. Be respectful inclusive and professional in all interactions. Harassment and hateful conduct are not allowed. Contributors who violate these expectations may be removed from the project.
